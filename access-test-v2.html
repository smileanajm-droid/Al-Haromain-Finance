Uji pembatasan akses unit

Menguji sesi login dan akses baca pada tabel keuangan. Tidak membuat, mengubah, atau menghapus data.

Keamanan: gunakan akun uji. Hanya gunakan Project URL dan publishable/anon key. Jangan pernah gunakan secret key/service_role di frontend. Jangan masukkan data siswa asli untuk pengujian.

UUID unit lain hanya dipakai untuk menguji bahwa query ke unit lain menghasilkan 0 baris. Jangan masukkan nama atau data siswa.

Siap. Pastikan supabase-config.js sudah terkonfigurasi di GitHub Pages.

Hasil pemeriksaan

Catatan: jika tabel belum memiliki data, hasil 0 baris tidak membuktikan sepenuhnya bahwa RLS benar. Uji lintas unit paling kuat dilakukan dengan UUID unit lain yang diketahui dan data uji yang aman.
